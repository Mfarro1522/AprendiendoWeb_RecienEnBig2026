como formatear tu pc:

  1. busca y almacena tus archivos importantes
  2. prepara un dispositivo usb
  3. crea un iso con el sistema operativo que usas
  4. con el usb listo apaga la pc
  5. al encender nuevamente aprieta el boton para entrar a la bios(f12 generalmente)
  6. cambia el arranque para que sea el usb
  7. si es windows puedes:
    • formatear
    • reparar
    • instalar nuevamente y limpio el so
  8. haz lo que prefieras y listo tu pc como nueva

glosario

so
sistema operativo
iso
imagen del sistema operativo
formatear
coloquialmente como reinciar de fabrica
